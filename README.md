# hack-5abba766-orbit-jr

Career Quest — проект команды orbit.jr для HackAlem AI. Приложение должно помогать сотруднику выбрать шаг развития с объяснением, пересчитывать прогресс и показывать HR разрывы по навыкам.

## Текущий статус

Подготовлены архитектура и TypeScript-контракты. Исполняемого приложения, Dockerfile и миграций пока нет; запуск сервера и AI ещё не проверен.

- [Полная архитектура бэкенда](docs/BACKEND.md)
- [Общие контракты для UI, backend и AI](contracts/backend.ts)

## Контракт будущей поставки

Жюри запускает проект на своём компьютере: Docker с Compose, `.env` по примеру и официальный датасет в `data/source/`. Целевая команда после реализации:

```sh
docker compose up --build
```

Приложение открывается на `http://localhost:3000`. SQLite создаётся автоматически внутри локального запуска, отдельный сервер БД не нужен. Изменения сохраняются в Docker volume. Внешний LLM API использует ключ из `.env`; без ключа предусмотрены рекомендации по правилам с явной пометкой режима.

Перед сдачей этот раздел должен быть заменён проверенными инструкциями: подготовка файлов и окружения, демо-аккаунты, запуск, импорт профилей жюри, остановка, сохранение и явный сброс состояния. Секреты, официальный датасет и локальная база в репозиторий не добавляются.
