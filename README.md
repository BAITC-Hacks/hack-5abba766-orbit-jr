# hack-5abba766-orbit-jr

Career Quest — проект команды orbit.jr для HackAlem AI. Приложение должно помогать сотруднику выбрать шаг развития с объяснением, пересчитывать прогресс и показывать HR разрывы по навыкам.

## Текущий статус

В frontend/ есть интерактивный Next.js / React / TypeScript UI-прототип на явно обозначенных демонстрационных данных. Подготовлены полная архитектура бэкенда и общие TypeScript-контракты. Реальный backend, авторизация, LLM и импорт пока не подключены; Dockerfile и миграции ещё предстоит реализовать.

## Запуск существующего UI-прототипа

Требуется Node.js 22 LTS. Все следующие команды выполняются в frontend/:

```sh
cd frontend
npm ci
npm run dev
```

Открыть http://localhost:3000/employee или http://localhost:3000/hr.

```sh
npm run build
npm run typecheck
```

Прототип включает профиль, карьерную цель, навыки, каталог с поиском, историю, симуляцию завершений, HR-предпросмотр и локальную предварительную проверку JSON. Он использует авторские фикстуры; HR-данные не синхронизированы с действиями сотрудника, а проверка JSON пока не является серверным импортом. Ключи API и официальный датасет не включены.

Исходники, зависимости и конфигурация Next-приложения находятся в frontend/. Серверные модули будут добавлены в frontend/src/server, HTTP-обработчики — в frontend/src/app/api. Общие документы и контракты находятся в корневых docs/ и contracts/.

## Контракт будущей полной поставки

Этот сценарий ещё не реализован и должен быть проверен перед сдачей. Жюри клонирует репозиторий, готовит .env по примеру и кладёт официальный датасет в data/source/. Целевая команда из корня репозитория:

```sh
docker compose up --build
```

Приложение открывается на http://localhost:3000. SQLite создаётся автоматически внутри локального запуска, отдельный сервер БД не нужен. Изменения сохраняются в Docker volume. Внешний LLM API использует ключ из .env; без ключа предусмотрены рекомендации по правилам с явной пометкой режима.

Перед сдачей этот раздел дополняется проверенными инструкциями: подготовка файлов и окружения, демо-аккаунты, импорт профилей жюри, остановка, сохранение и явный сброс состояния. Секреты, официальный датасет и локальная база в репозиторий не добавляются.
