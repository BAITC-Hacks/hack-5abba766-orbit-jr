# Career Quest — интерфейс

React/Next.js интерфейс подключён к серверному пакету `../backend`. Профиль, цели, история, рекомендации, выполнение, HR и импорт используют HTTP API и PostgreSQL. Fixture/localStorage не заменяют бизнес-состояние.

Запуск всего проекта — **из корня репозитория**, по [главному README](../README.md):

```sh
npm ci
docker compose up -d db
npm run dev
```

Предварительно нужны `.env` и четыре исходных файла в `data/source/`. Страницы: `/employee`, `/hr`. Вход: demo-аккаунты из главного README.

В `/demo` сохранён отдельный визуальный прототип команды с fixtures и localStorage. Основные страницы работают с настоящим API; для проверки бизнес-сценариев используйте их.

Общий контракт — [contracts/backend.ts](../contracts/backend.ts). HTTP-транспорт в `src/lib/api.ts` распаковывает `{data,meta}`, сохраняет коды ошибок, передаёт cookie, версии и ключи повторных запросов. API-обработчик `src/app/api/[...path]/route.ts` делегирует запросы пакету `@career-quest/backend`.

Для внешней модели нужны серверные переменные `LLM_API_KEY` и `LLM_MODEL`; в клиентский bundle ключ не попадает. Без настройки отображается подбор по правилам. Стили — существующий CSS с системным запасным шрифтом; при отсутствии Google Fonts интерфейс остаётся доступен.

Проверка интерфейса и локальные QA-сценарии: [QA.md](QA.md).
